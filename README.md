# 🎵 Music Player (Java)

A simple console-based Music Player application built using Java that allows users to play, pause, resume, stop, and reset audio playback.  
This project was created as a hands-on exercise to strengthen core Java fundamentals and understand audio handling using the Java Sound API.

---

## 📌 Project Overview

The Music Player is a command-line application that plays `.wav` audio files and provides basic playback controls through user input.  
It focuses on practical Java concepts such as file handling, exception management, and working with external APIs.

---

## ✨ Features

- Play audio files (.wav format)
- Pause and resume music playback
- Stop and reset the audio
- Interactive command-line controls
- Lightweight and easy to run
- Uses Java’s built-in audio libraries

---

## 🛠 Tech Stack

- **Language:** Java  
- **Audio Handling:** Java Sound API (`Clip`, `AudioInputStream`)  
- **Core Concepts Used:**
  - File I/O
  - Exception handling
  - Resource management (try-with-resources)
  - Console-based user interaction
